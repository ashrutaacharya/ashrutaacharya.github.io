# AGENTS.md

## Project goal

This is a professional personal website for an academic/professional job-market year.
The site should be clean, accessible, mobile-friendly, and easy to maintain.

## Content rules

- Do not invent publications, positions, degrees, awards, courses, or affiliations.
- Use concise professional language.
- Keep the homepage skimmable.
- Preserve all links to CV, papers, Google Scholar, GitHub, and contact information.
- Do not include home address, personal phone number, private drafts, or confidential data.

## Design rules

- Use semantic HTML.
- Make the site responsive on mobile and desktop.
- Use readable typography and strong contrast.
- Add alt text for images.
- Keep dependencies minimal.

## Verification

Before considering work complete:
- Check that all internal links work.
- Check that cv.pdf opens.
- Check mobile layout.
- Check that the homepage loads without console errors.
